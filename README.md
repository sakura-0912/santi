# 三体 · 倒计时

一个只供本机个人游玩的《三体》第一部同人改编网页游戏。单机、无联网、无账号、无内购；请勿传播或用于公开发行。

## 怎么启动

在项目根目录运行：

```powershell
node build/app/server.mjs --port=4271
```

然后打开：

```text
http://127.0.0.1:4271/
```

也可以直接打开 `build/app/index.html`，但推荐用上面的本地服务器，避免不同浏览器对本地文件的限制。

Windows 下也可以双击或右键运行 `启动游戏.ps1`，它会启动本地服务器并打开浏览器。

## 怎么玩

- 点击场景里的物件收集线索；右侧是证据夹，手机端用顶部“证据”按钮打开。
- 在证据夹里点“提交判断”，用正确数量的证据组合形成结论。判断会提高洞察。
- 三体游戏每回合选一个文明行动；太阳预报可能出错，脱水与迁徙能降低灾难伤害。
- 古筝行动要选择伏击点、丝距、时机、首要目标，并决定是否警告平民。
- 空格/回车推进对话，数字键 1–3 选择选项，Esc 关闭弹窗。

## 单周目

约 30–50 分钟。三章、三次文明模拟、三次判断、四种结局。终局可以在结局页重开，尝试不同选择。

## 结构

```text
build/app/
├── index.html     页面骨架与图标
├── styles.css     视觉、响应式与动效
├── rules.js       纯规则：文明模拟、判断、终局结算
├── game.js        叙事、状态机、存档、界面与音效
├── server.mjs     本地静态服务器
└── favicon.svg
build/tests/
└── rules.test.cjs 规则回归
qa/
├── verify.mjs     真实 Edge 端到端验收
├── verification.json
└── playtest-report.md
```

## 验证

```powershell
node build/tests/rules.test.cjs
node qa/verify.mjs
```

最近一次验收：六项自动检查全部 `PASS`，规则回归 14/14。详见 `qa/verification.json`。
